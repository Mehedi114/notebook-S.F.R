# S.F.R Smart Notebook (`SUMON FROM RANGPUR`)

Official ultra-lightweight Hard PWA Smart Script Notebook & Background Voice Reader for the **SUMON FROM RANGPUR** YouTube channel (`https://youtube.com/channel/UCj-7BQtODymbgBDWNwxjSZg`).

## Key Features
- **Installable Hard PWA + Offline Cache**: Activates Service Worker (`sw.js`) & Web App Manifest (`manifest.webmanifest`) immediately on entry so team members can install it as an app and read/listen even on spotty networks.
- **Background Smart Voice Reader**: Plays Full A–Z Scripts or Short Extracted Dialogues with an HTML5 `<audio>` PCM keep-alive stream + Lock-Screen / Notification Bar `MediaSession` controls so audio continues even when leaving the browser or locking the phone.
- **Automatic Dialogue & Basic Instruction Extractor**: Write/paste one complete A–Z script—the system automatically extracts **only Dialogues** (with per-character filters) and **Basic Shooting Instructions** to save time.
- **Clean Workspace & Official YouTube Channel Integration**: Direct buttons for the official **SUMON FROM RANGPUR** YouTube Channel, `Videos`, `Shorts`, and `Subscribe`.

## Quick Start

```bash
npm install
npm run build
npm start
```

Run automated tests:

```bash
npm test
```
